What is PDL?

Pairwise Difference Learning turns a hard multiclass problem into an easy binary one. Instead of asking “what class is this point?”, it asks “are these two points the same class?” — so n training rows become n² pairwise examples, squeezing far more signal out of small datasets. For regression, the model learns the difference between pairs of targets and averages the anchored predictions.

Rule of thumb from the paper: PDL shines on small (< 2000 rows), balanced, fully observed tabular data with tree-based learners; it loses ground with unbalanced classes, missing values, very large datasets, or parametric base models (linear, SVM, kNN, MLP).
